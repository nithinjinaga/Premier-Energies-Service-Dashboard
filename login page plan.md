# Visitor Tracking with Email OTP + Google Sheets Logging

## Context
The dashboard is shared with internal team members and company leadership. Nithin wants to know **who** specifically opens the dashboard — not just visitor counts. The solution uses email-based OTP verification so identities are confirmed, with all visits logged to a Google Sheet.

## Architecture Overview

```
Visitor opens dashboard
  → Login screen (email input)
  → Calls Google Apps Script → sends OTP email via Gmail
  → Visitor enters OTP → Apps Script verifies it
  → On success: dashboard loads, visit logged to Google Sheet
  → Email stored in localStorage (auto-login on return visits)
```

**Two components to build:**

### Component 1: Google Apps Script (backend — deployed once by Nithin)

A free Google Apps Script web app that handles:
1. **`POST ?action=sendOTP`** — generates a 6-digit code, stores it in Script Properties (with 5-min expiry), sends it to the visitor's email via `GmailApp.sendEmail()`
2. **`POST ?action=verifyOTP`** — checks the code, if valid logs the visit to a Google Sheet (email, timestamp, user agent, screen size) and returns success
3. **`POST ?action=logVisit`** — for returning visitors (already verified via localStorage), just logs the visit without re-verifying

I will provide the complete Apps Script code as a separate file (`apps_script.js`) with setup instructions.

### Component 2: Login Gate in Dashboard (frontend)

Modifications to `build_dashboard.py` (which generates `index.html`):

1. **Add a login overlay** — a full-screen modal that covers the dashboard content. Two states:
   - Email input + "Send OTP" button
   - OTP input + "Verify" button (shown after OTP is sent)

2. **Add gate logic** — on page load:
   - Check `localStorage` for a previously verified email
   - If found → log the return visit (silent call to Apps Script) → show dashboard
   - If not found → show login overlay, hide dashboard content

3. **CSS for the login overlay** — styled to match the existing dashboard design (same fonts, colors, border-radius)

4. **Apps Script URL placeholder** — a `__TRACKER_URL__` placeholder in the HTML template, replaced by `build_dashboard.py` from an env var or config constant

## Setup Steps for Nithin (one-time, ~10 minutes)

1. Go to [script.google.com](https://script.google.com) → New Project
2. Paste the contents of `apps_script.js`
3. Click Deploy → New Deployment → Web App → "Anyone" can access → Deploy
4. Copy the web app URL
5. Paste it as the `TRACKER_URL` value in `build_dashboard.py`
6. Run `python build_dashboard.py` → push to GitHub → Vercel auto-deploys
